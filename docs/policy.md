# 本地化边界

## 远程套件可保存

- 包名、固定版本、npm registry 元数据。
- 目标文件相对路径和官方上游 SHA-256。
- 汉化 scope 与 keepEnglish 边界。
- 不依赖译文内容的验证工具与合成测试。

## 远程套件不得保存

- 中英替换对（`from`/`to`）。
- 汉化版文件哈希。
- 完整 manifest、备份、安装包、tarball。
- 凭据、模型配置、会话和本机绝对路径。

## 可以汉化

TUI、CLI 帮助、按钮、菜单、状态、通知、doctor 和面向用户的错误说明；产品内置摘要或引导文案中不改变模型能力与工具协议的部分。

## 保持原文

工具名、Slash command、命令参数、路径、URL、环境变量、API、HTTP、CLI、TUI、Provider、模型名称、模型 ID、JSON/schema、selector、状态枚举、模型可见工具描述与结果协议、官方系统提示词、外部服务响应和原始错误正文。

同一字符串既服务 TUI 又服务模型协议时，默认不翻译。
